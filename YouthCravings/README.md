# 🍿 YouthCravings

> **Snack your mood. Enjoy your moment. ✦**

YouthCravings adalah landing page modern yang dibuat untuk menghadirkan dunia snack dan cemilan ringan dalam tampilan yang fun, fresh, dan minimalis.

Website ini menjadi tempat untuk menemukan berbagai inspirasi cemilan berdasarkan mood—mulai dari yang manis, gurih, crispy, sampai fresh. 🍪🍟🍓

## ✨ Features

- 🎨 Modern & minimalistic design
- 💙 Light blue, yellow, and white color palette
- 🍿 Snack categories based on mood
- ❤️ Favorite button
- 🎲 Surprise Me — rekomendasi snack secara random
- 📱 Fully responsive
- ✨ Smooth animations & hover effects
- 🧭 Simple and intuitive navigation

## 🛠️ Built With

- HTML
- CSS
- JavaScript

## 🎯 Concept

YouthCravings dibuat dengan konsep:

**Simple. Fresh. Fun. Delicious.**

Bukan cuma tentang cemilan, tapi tentang bagaimana snack bisa menjadi bagian kecil dari setiap mood dan momen.

> *Life is too short for boring snacks.* 🍿
